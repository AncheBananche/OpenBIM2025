# 41943 A2: OpenBIM Analysis

*Group 2: s243577 & s213839*

- The chosen use case is to verify whether the desk space in each room is BR18 compliant.
- This is intended for use by architects.
- For htis project, we will be taking on the analyst role.
- We will be using the Building2516 (ARCH-25-16-D) for our analysis.


- For this tool, knowledge on the BR18 regulations is a necessity to check if requirements are being met by architects.
- In the IFC file script, exctracting information on furntiture and room areas is part of the final calculationas to find wether the room is accepted or rejected. This information will be extracted to an excel file.
- We are particularly intrested in the workspace desk furniture as this is where strict BR18 regulations require an adequate working environment.
- The critical input data will be the IFC model file where information can be extracted. Additionally, the BR18 document can be inputted for information or just relevant information from said document used within the code.
- Other use cases for this code could be to change the regulation its investigating, such as facade transparency requirements, and to compare the amount found with the BR18 requirements.
